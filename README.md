# VideoFactory — versões

Aqui ficam os instaladores do VideoFactory para Windows.

- Baixe a versão mais nova em **Releases** (à direita) → `VideoFactory-Setup-x.y.z.exe`.
- Quem já tem o app instalado recebe as atualizações sozinho (Ajustes › Atualização automática).

## Instalar manualmente
Baixe todas as partes de `releases/<versão>/` e junte no Windows (Prompt de Comando, na pasta das partes):
`copy /b VideoFactory-Setup-4.4.2.exe.part00+VideoFactory-Setup-4.4.2.exe.part01+... VideoFactory-Setup-4.4.2.exe`
